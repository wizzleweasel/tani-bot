## 🎯 YouTube SEO Methodology

### Why YouTube Matters for Indonesian Farmers
- **Educational videos** on good agricultural practices are disseminated via YouTube + WhatsApp
- Farmers prefer **visual, practical solutions** over text-based guides
- "How-to" and troubleshooting content dominates search behavior
- Mobile-first: farmers search while in the field

### Keyword Research Strategy (per Semrush, Ahrefs, vidIQ)
1. **Think like a viewer** - specific questions, not broad terms
2. **Long-tail keywords** - 3-5 words, lower competition, higher intent
3. **"How to" + "What is" formats** - explicitly good for SEO
4. **Use autocomplete** - YouTube's suggestions = real queries
5. **Focus on problems** - pest identification, yellow leaves, low yield

## 📁 Dataset Structure for Supabase

### Table: `youtube_search_queries`
```sql
CREATE TABLE youtube_search_queries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  query_text TEXT NOT NULL,
  language TEXT DEFAULT 'id', -- 'id' or 'en'
  cluster TEXT NOT NULL, -- 'pest_disease', 'fertilizer', 'planting', etc.
  intent TEXT NOT NULL, -- 'informational', 'troubleshooting', 'how_to', 'commercial'
  search_volume_est INTEGER, -- estimated monthly searches
  competition TEXT, -- 'low', 'medium', 'high'
  youtube_video_count INTEGER, -- number of existing videos
  priority INTEGER DEFAULT 5, -- 1-10, 10 = highest priority
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Table: `question_answer_pairs` (for conversation training)
```sql
CREATE TABLE question_answer_pairs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  question_id UUID REFERENCES youtube_search_queries(id),
  question_text TEXT NOT NULL,
  question_language TEXT DEFAULT 'id',
  answer_text TEXT NOT NULL,
  answer_language TEXT DEFAULT 'id',
  answer_source TEXT, -- 'expert', 'research_paper', 'government_guide', 'farmer_experience'
  confidence_score DECIMAL(3,2), -- 0.00-1.00
  tags TEXT[], -- ['rice', 'pest', 'wereng', 'organic']
  verified BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Table: `video_transcripts` (for RAG expansion)
```sql
CREATE TABLE video_transcripts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  youtube_url TEXT NOT NULL,
  video_title TEXT,
  channel_name TEXT,
  transcript_text TEXT,
  language TEXT DEFAULT 'id',
  duration_seconds INTEGER,
  view_count INTEGER,
  published_date DATE,
  topics TEXT[],
  embedding VECTOR(384),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

   - Plantix disease database

### Phase 2: Video Transcripts (Week 3-4)
1. **Scrape top 50 agriculture YouTube videos** (Indonesian)
2. **Extract transcripts** (use YouTube auto-captions + manual correction)
3. **Chunk into Q&A format** for RAG
4. **Generate embeddings** (384-dim) and store in Supabase

### Phase 3: User Conversation Logs (Week 4+)
1. **Simulate 500+ conversations** based on keyword clusters
2. **Include edge cases:**
   - Mixed language (Bahasa + English code-switching)
   - Vague queries ("daun kuning" → need follow-up questions)
   - Multi-turn troubleshooting
3. **Store in `conversations` + `messages` tables**

## 📈 Sample Q&A Pairs (Ready for Insertion)

### Q1: Wereng Coklat (Brown Planthopper)
**Q (ID):** "Cara mengatasi wereng coklat pada padi?"  
**Q (EN):** "How to control brown planthopper on rice?"  
**A (ID):** "Wereng coklat dapat dikendalikan dengan: (1) Tanam varietas tahan seperti IR64 atau Ciherang, (2) Keringkan sawah bergantian (intermittent irrigation), (3) Gunakan insektisida buprofezin jika populasi >10 ekor per rumpun, (4) Pertahankan musuh alami seperti laba-laba dan kumbang mirid. Hindari penyemprotan dini yang merusak musuh alami."  
**A (EN):** "Brown planthopper can be controlled by: (1) Plant resistant varieties like IR64 or Ciherang, (2) Use intermittent irrigation (dry-flood cycles), (3) Apply buprofezin insecticide if population exceeds 10 per hill, (4) Preserve natural enemies like spiders and mirid bugs. Avoid early spraying that destroys natural enemies."  
**Tags:** ['rice', 'pest', 'wereng', 'brown-planthopper', 'ipm']  
**Confidence:** 0.95  
**Source:** Plantix + IRRI

### Q2: Yellow Leaves
**Q (ID):** "Kenapa daun padi menguning?"  
**Q (EN):** "Why are rice leaves turning yellow?"  
**A (ID):** "Daun padi menguning bisa disebabkan oleh: (1) Kekurangan nitrogen - berikan pupuk urea 100-200 kg/ha, (2) Serangan wereng - periksa pangkal batang, (3) Kekurangan air - pastikan irigasi cukup, (4) Tanah asam - berikan kapur pertanian. Periksa gejala lain untuk diagnosis tepat."  
**A (EN):** "Yellow rice leaves can be caused by: (1) Nitrogen deficiency - apply urea 100-200 kg/ha, (2) Planthopper attack - check stem base, (3) Water shortage - ensure adequate irrigation, (4) Acidic soil - apply agricultural lime. Check other symptoms for accurate diagnosis."  
**Tags:** ['rice', 'nutrient-deficiency', 'nitrogen', 'yellow-leaves', 'diagnosis']  
**Confidence:** 0.90  
**Source:** Extension guides

### Q3: Organic Fertilizer
**Q (ID):** "Cara membuat pupuk organik cair dari limbah dapur?"  
**Q (EN):** "How to make liquid organic fertilizer from kitchen waste?"  
**A (ID):** "Bahan: (1) Sisa sayur/buah 5kg, (2) Gula merah 100g, (3) Air cucian beras 2L, (4) EM4 50ml. Cara: Campur semua, fermentasi 2-3 minggu, aduk setiap 3 hari. Siap saat bau busuk hilang dan warna coklat tua. Encerkan 1:10 sebelum semprot."  
**A (EN):** "Ingredients: (1) Vegetable/fruit scraps 5kg, (2) Brown sugar 100g, (3) Rice washing water 2L, (4) EM4 50ml. Method: Mix all, ferment 2-3 weeks, stir every 3 days. Ready when foul smell disappears and turns dark brown. Dilute 1:10 before spraying."  
**Tags:** ['organic-fertilizer', 'kitchen-waste', 'fermentation', 'poc', 'mol']  
**Confidence:** 0.92  
**Source:** Wikibooks Indonesia
