## 🧠 LESSONS LEARNED

1. **Document as you go** - Without `HUGGINGFACE_INTEGRATION.md`, we'd have lost the 3 RAG dataset categories
2. **Single channel is limiting** - Telegram works for 1:1, not parallel subagents
3. **1 bot > 10 bots** - Route by channel, not by bot identity
4. **Discord hosting is free** - Server + bot app both hosted by Discord
5. **GitHub Issues = permanent record** - Better than chat history for task tracking
