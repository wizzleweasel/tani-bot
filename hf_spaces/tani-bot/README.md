# 🌾 TaniBot - Asisten Pertanian Indonesia

Asisten pertanian berbasis AI untuk petani Indonesia.

## ✨ Fitur

- 3,000+ dokumen pertanian
- 100% Bahasa Indonesia
- 19 komoditas (padi, jagung, cabe, kopi, dll)
- Response time <2 detik
