# 🌤️ TaniBot Cuaca

Sistem Prakiraan Cuaca untuk Petani Indonesia

## Features

- ☀️ 7-day forecast (Open-Meteo)
- 📅 30-day forecast (NASA POWER)
- 📈 12-week trends (EMA)
- 🇮🇩 Bahasa Indonesia UI
- 📍 Location selector

## Usage

1. Select location from sidebar
2. Click "🔍 Cek Cuaca"
3. View forecasts

## Data Sources

- Open-Meteo: 7-day weather forecast
- NASA POWER: 30-day agricultural forecast
- EMA: 12-week seasonal trends
